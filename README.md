# derech-kohanim-data

נתוני הפוליגונים הגולמיים של אזורי דרך כהנים. ריפו ייעודי, מקור האמת של הנתונים לפני עיבוד.

## תוכן

- `areas.json` - אוסף האזורים בפורמט GeoJSON עטוף: `{ success, features, data: { type:"FeatureCollection", features:[...] } }`. שים לב שהקובץ מתחיל ב-BOM.

כל אזור הוא פוליגון עם המאפיינים:

| שדה | תיאור |
|------|--------|
| `name` | כותרת הסיבה בעברית |
| `city` | עיר |
| `street` | רחוב, כשרלוונטי |
| `description` | ההסבר ההלכתי המלא |
| `level` | רמה: `א`, `ב`, `ג`, או `A` |

הקואורדינטות בסדר GeoJSON תקני, `[lng, lat]`.

## רמות

| רמה | מיפוי לשכבת חומרה | משמעות |
|------|---------------------|---------|
| `א` | `basic` | איסור גמור לכו"ע |
| `ב` | `taharat` | הכרעת התאחדות טהרת כהנים |
| `ג` | `machmirim` | חשש במחלוקת, יש מחמירין |
| `A` | טבלת `danger_zones` נפרדת | שטח A של אוסלו, ציר ביטחוני נפרד |

## שימוש

השרת (`derech-kohanim-api`) מייבא את הקובץ הזה למסד הנתונים בפקודה אחת שמאפסת וטוענת מחדש. ראה את ה-README של השרת.

## הערה

זהו מאגר נתונים, לא קוד. שינויים כאן משפיעים ישירות על מה שמוצג ונחסם למשתמשים, ולכן יש לעדכן אותו בזהירות ולתעד את מקור כל אזור.
